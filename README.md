## Customise the colours

Open `index.html` and edit the values at the top of the `<style>` section:

```css
:root{--pitch:#0A4A32; --red:#C8102E; --gold:#FFCB05; ...}
```

For Real Madrid colours, try white `#FFFFFF`, navy `#00529F` and gold `#FEBE10`.
